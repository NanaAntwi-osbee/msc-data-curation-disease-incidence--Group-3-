# msc-data-curation-disease-incidence--Group-3-
This curated dataset tracks HIV, Malaria, and Tuberculosis incidence across Sub-Saharan Africa (2000-2025) using WHO Global Health Observatory data. Cleaned to distinguish counts from rates, its purpose is to support data-driven disease burden monitoring and epidemiological forecasting in the region.
## Data Provenance
* **Original Data Provider:** World Health Organization (WHO) Global Health Observatory (GHO)
* **Portal Link:** [https://www.who.int/data/gho](https://www.who.int/data/gho?utm_source=copilot.com)[cite: 1]
* **Source Datasets:** 
  * Estimated number of people (all ages) living with HIV
  * Estimated malaria incidence (per 1000 population at risk)
  * Number of incident tuberculosis cases
* **Date of Retrieval:** September 24, 2026
* **Original Filenames:** `HIV.xlsx`, `Malaria.xlsx`, `TUBERCULOSIS.xlsx`
